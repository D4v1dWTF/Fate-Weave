## 🌟 中文版

### 遊戲簡介

《Fate Weave》是一款由 **AI 即時生成敘事** 的人生模擬 RPG。你將扮演一名「節點行者」，從 0 歲開始，在充滿命運絲線的奇幻世界中經歷完整一生。

每一次選擇 — 無論是漫步、研讀、工作、社交或探索 — 都會影響你的屬性、人際關係、財富與最終命運。遊戲融合了人生模擬、RPG 養成與動態事件，讓每局遊戲都獨一無二。

> 即使沒有 AI API 金鑰，也能使用內建 **40+ 靜態事件** 完整遊玩。

---

### 主要特色

- **完整人生旅程**：從 0 歲到老年，經歷成長、學習、工作、衰老與終結。
- **AI 動態敘事**：場景、NPC 對話、隨機事件與工作經歷皆由 AI 生成，每次遊玩體驗不同。
- **角色創造系統**：擲骰決定屬性，搭配 22 種原創特徵（正面增益／負面減益），打造專屬角色。
- **行動點系統**：每年 5 個行動點，自由分配於漫步、研讀、工作、社交、探索。
- **年齡匹配的工作**：幼年做家務、青少年打工、成年專業工作 — 隨著年齡增長，工作內容與報酬動態變化。
- **隱藏事件與科技樹**：30 歲後解鎖科技，可能觸發正面或負面隱藏事件，影響人生走向。
- **背包與商店**：購買、使用、販售物品（治療藥水、力量指環等）。
- **圖鑑系統**：記錄已解鎖的結局與隱藏事件，隨時查看進度。
- **8 種結局 × 4 種版本 = 32 種結局敘事**，每個結局都包含「世界的反應」。
- **內容安全機制**：所有 AI 生成內容皆經過過濾，適合全年齡層。

🌟 English Version
Game Description
Fate Weave is a life simulation RPG powered by real-time AI narrative generation. You play as a "Node Walker," starting from age 0 and living a complete life in a fantasy world woven with threads of fate.

Every choice — whether strolling, studying, working, socializing, or exploring — affects your attributes, relationships, wealth, and ultimate destiny. The game blends life simulation, RPG progression, and dynamic events to ensure every playthrough is unique.

No AI API key? No problem! The game includes 40+ static events for a fully playable experience.

Key Features
Full Life Journey: From infancy to old age — grow, learn, work, age, and face your final fate.

AI-Powered Storytelling: Scenes, NPC dialogues, random events, and work scenarios are dynamically generated by AI.

Character Creation: Roll attributes (4d6 drop lowest) and choose from 22 original traits (positive buffs / negative debuffs) to build your unique character.

Action Point System: 5 action points per year — spend them on walking, reading, working, socializing, or exploring.

Age-Matched Work: Tasks evolve as you age — from childhood chores to teenage odd jobs, to professional careers.

Hidden Events & Tech Tree: Unlock technologies after age 30, which may trigger positive or negative hidden events.

Inventory & Shop: Buy, use, and sell items (healing potions, strength rings, etc.).

Codex System: Track unlocked endings and hidden events.

8 Endings × 4 Versions = 32 Unique Epilogues, each with a "world reaction."

Content Safety: All AI-generated content is filtered to be age-appropriate.
